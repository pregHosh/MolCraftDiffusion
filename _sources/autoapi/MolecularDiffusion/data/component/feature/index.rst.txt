.. py:class:: NodeFeaturizer(atom_vocab: list, use_ohe: bool = True, geom_feature: str = None, allow_unknown: bool = False)

   Unified node featurization for both GraphDataset and PointCloudDataset.

   Supports:
   - OHE (one-hot encoding) of atom types
   - Geom-based features from atomic numbers and coordinates

   Usage:
       featurizer = NodeFeaturizer(atom_vocab, use_ohe=True, geom_feature="geometric_fast")
       features = featurizer.featurize_all(atom_symbols, charges, coords)

   :param atom_vocab: List of atom symbols for OHE encoding
   :param use_ohe: Whether to include one-hot encoding of atom type
   :param geom_feature: Name of geom feature type (None for OHE only)
   :param allow_unknown: Whether to allow unknown atoms in OHE


   .. py:method:: available_features() -> list
      :classmethod:


      Return list of available feature names.



   .. py:method:: compute_geom(charges: torch.Tensor, coords: torch.Tensor) -> torch.Tensor

      Compute geom features from atomic numbers and coordinates.

      :param charges: Atomic numbers tensor (N,)
      :param coords: Coordinates tensor (N, 3)

      :returns: Geom features tensor (N, F)



   .. py:method:: compute_ohe(atom_symbols: list) -> torch.Tensor

      Compute one-hot encoding for atom symbols.

      :param atom_symbols: List of atom symbols (e.g., ['C', 'H', 'O'])

      :returns: OHE tensor (N, len(vocab)) or (N, len(vocab)+1) if allow_unknown



   .. py:method:: featurize(charges: torch.Tensor, coords: torch.Tensor) -> torch.Tensor

      Compute geom features only (legacy interface).



   .. py:method:: featurize_all(atom_symbols: list, charges: torch.Tensor, coords: torch.Tensor) -> torch.Tensor

      Compute all features: OHE + geom (if specified).

      :param atom_symbols: List of atom symbols
      :param charges: Atomic numbers tensor (N,)
      :param coords: Coordinates tensor (N, 3)

      :returns: Combined features tensor (N, total_dim) or None if no features
