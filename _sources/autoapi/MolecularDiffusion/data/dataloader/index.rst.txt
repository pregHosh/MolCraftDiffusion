.. py:class:: DataLoader(dataset, batch_size=1, shuffle=False, sampler=None, batch_sampler=None, num_workers=0, collate_fn=graph_collate, **kwargs)

   Bases: :py:obj:`torch.utils.data.DataLoader`


   Extended data loader for batching graph structured data.

   See `torch.utils.data.DataLoader`_ for more details.

   .. _torch.utils.data.DataLoader:
       https://pytorch.org/docs/stable/data.html#torch.utils.data.DataLoader

   :param dataset: dataset from which to load the data
   :type dataset: Dataset
   :param batch_size: how many samples per batch to load
   :type batch_size: int, optional
   :param shuffle: set to ``True`` to have the data reshuffled at every epoch
   :type shuffle: bool, optional
   :param sampler: sampler that draws single sample from the dataset
   :type sampler: Sampler, optional
   :param batch_sampler: sampler that draws a mini-batch of data from the dataset
   :type batch_sampler: Sampler, optional
   :param num_workers: how many subprocesses to use for data loading
   :type num_workers: int, optional
   :param collate_fn: merge a list of samples into a mini-batch
   :type collate_fn: callable, optional
   :param kwargs: keyword arguments for `torch.utils.data.DataLoader`_
