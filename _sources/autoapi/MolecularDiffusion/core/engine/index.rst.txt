.. py:class:: Engine(task, train_set, valid_set, test_set, optimizer=None, collate_fn=None, scheduler=None, batch_size=1, gradient_interval=1, clipping_gradient=None, clip_value=1, ema_decay=0.0, num_worker=0, pin_memory=True, logger='logging', log_interval=100, project_wandb=None, name_wandb=None, dir_wandb=None, tags_wandb=None, debug=False, progress_bar_metrics='all')

   Bases: :py:obj:`MolecularDiffusion.core.Configurable`


   General class that handles everything about training and test of a task.

   If :meth:`preprocess` is defined by the task, it will be applied to ``train_set``, ``valid_set`` and ``test_set``.

   :param task: task
   :type task: nn.Module
   :param train_set: training set
   :type train_set: data.Dataset
   :param valid_set: validation set
   :type valid_set: data.Dataset
   :param test_set: test set
   :type test_set: data.Dataset
   :param optimizer: optimizer
   :type optimizer: optim.Optimizer
   :param collate_fn: collate function for batching (default to :func:`data.graph_collate`)
   :type collate_fn: callable, optional
   :param scheduler: scheduler
   :type scheduler: lr_scheduler._LRScheduler, optional
   :param batch_size: batch size of a single CPU / GPU
   :type batch_size: int, optional
   :param gradient_interval: perform a gradient update every n batches.
                             This creates an equivalent batch size of ``batch_size * gradient_interval`` for optimization.
   :type gradient_interval: int, optional
   :param clipping_gradient: toggle to clip the gradient (by norm or value, default is None)
   :type clipping_gradient: str, optional
   :param clip_value: clip value (value of norm), or provide gradient gradient queue
   :type clip_value: float, Queue, optional
   :param ema_decay: decay rate for exponential moving average
   :type ema_decay: float, optional
   :param num_worker: number of CPU workers per GPU
   :type num_worker: int, optional
   :param pin_memory: pin memory for faster data transfer
   :type pin_memory: bool, optional
   :param logger: logger type or logger instance.
                  Available types are ``logging`` and ``wandb``.
   :type logger: str or core.LoggerBase, optional
   :param log_interval: log every n gradient updates
   :type log_interval: int, optional
   :param project_wandb: project name for wandb
   :type project_wandb: str, optional
   :param name_wandb: name for wandb
   :type name_wandb: str, optional
   :param dir_wandb: directory for wandb
   :type dir_wandb: str, optional
   :param debug: Toggle debug mode
   :type debug: bool, optional

   .. py:method:: train(num_epoch=1, num_step=None, batch_per_epoch=1, use_amp=False, precision='bf16')

      Train the model.

      Iterates over the WHOLE dataset for each epoch unless num_step is provided.

      :param num_epoch: number of epochs.
      :type num_epoch: int, optional
      :param num_step: total number of optimizer steps to perform.
                       If provided, training stops after this many updates.
      :type num_step: int, optional
      :param batch_per_epoch: Gradient Accumulation Steps.
                              The number of batches to accumulate gradients
                              for before performing an optimizer step.
                              Default is 1 (step every batch).
      :type batch_per_epoch: int, optional
      :param use_amp: whether to use automatic mixed precision (AMP).
      :type use_amp: bool, optional
      :param precision: precision to use for AMP ("bfloat16" or "float16").
      :type precision: str, optional

      :returns: metrics
      :rtype: dict
