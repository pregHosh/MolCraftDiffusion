MolecularDiffusion.core.engine_lightning
========================================

.. py:module:: MolecularDiffusion.core.engine_lightning

.. autoapi-nested-parse::

   PyTorch Lightning wrapper for MolecularDiffusion Task classes.

   This module provides a LightningModule that wraps existing Task classes
   (from tasks_esen.py, tasks_egt.py, tasks_egcl.py) to enable training
   with PyTorch Lightning infrastructure.

.. py:class:: EngineLightning(optimizer_config: Dict[str, Any], task: Optional[torch.nn.Module] = None, scheduler_config: Optional[Dict[str, Any]] = None, monitor_metric: Optional[Any] = None, model_config: Optional[Dict[str, Any]] = None, ema_decay: float = 0.0, gradnorm_queue: Optional[MolecularDiffusion.callbacks.Queue] = None, gradient_clip_algorithm: str = 'adaptive', sleep_every_N: int = 0, sleep_time: float = 60.0)

   Bases: :py:obj:`pytorch_lightning.LightningModule`, :py:obj:`MolecularDiffusion.core.Configurable`


   Lightning wrapper for MolecularDiffusion Task classes.

   This wraps any task (regression, guidance, diffusion) and adapts it
   to Lightning's training interface.

   :param task: The task module (e.g., PropertyPrediction, GeomMolecularGenerative)
   :type task: nn.Module
   :param optimizer_config: Configuration for optimizer
                            - optimizer_choice: str, one of ["adam", "adamw", "amsgrad", "radam"]
                            - lr: float
                            - weight_decay: float
                            - betas: tuple
                            - eps: float
   :type optimizer_config: dict
   :param scheduler_config: Configuration for learning rate scheduler
                            - scheduler: str or None
                            - scheduler_kwargs: dict
   :type scheduler_config: dict


   .. py:method:: configure_gradient_clipping(optimizer, gradient_clip_val, gradient_clip_algorithm)

      :param optimizer: The optimizer being used
      :param gradient_clip_val: Value from Trainer config (used for 'lightning' mode)
      :param gradient_clip_algorithm: Algorithm from Trainer config ('norm' or 'value')

   .. py:method:: on_load_checkpoint(checkpoint)

      Load EMA model state and distribution models from checkpoint.

      Handles:
      1. EMA state (new format: 'ema_model_state_dict' or old format: 'ema_model.*' keys)
      2. Distribution models: node_dist_model, prop_dist_model, n_node_dist
      3. Tabasco data_stats



   .. py:method:: on_save_checkpoint(checkpoint)

      Save task-specific distribution data to checkpoint.

      This saves:
      - For Tabasco: data_stats dictionary containing num_atoms_histogram
      - For other diffusion models: node_dist_model and prop_dist_model
      - EMA model state if enabled

      This ensures all data needed for generation is embedded in the checkpoint.
