   Generative evaluation callback for diffusion models.

   Generates molecules during validation and computes validity metrics.
   This callback runs the generative analysis from eval.py.

   :param n_samples: Number of molecules to generate
   :type n_samples: int
   :param batch_size: Batch size for generation
   :type batch_size: int
   :param metric: Primary metric to monitor
   :type metric: str
   :param output_dir: Directory to save generated molecules
   :type output_dir: str
   :param use_posebuster: Whether to use posebuster for validation
   :type use_posebuster: bool
   :param posebuster_timeout: Timeout for posebuster validation
   :type posebuster_timeout: int
