.. py:function:: evaluate(task: str, solver: MolecularDiffusion.core.Engine, epoch: int = 0, current_best_metric: float = torch.inf, best_checkpoints: list = None, logger: Literal['wandb', 'logging'] = 'logging', output_path: str = None, use_amp: bool = False, precision: str = 'bf16', **kwargs)

   Evaluates the performance of a trained model based on the specified task.

   For 'diffusion' tasks, it evaluates generative performance by sampling molecules,
   saving them, and analyzing their structural validity and connectivity.
   For 'property' or 'guidance' tasks, it evaluates predictive performance
   by calculating Mean Absolute Error (MAE).

   :param task: The type of task being evaluated ("diffusion", "property", or "guidance").
   :type task: str
   :param solver: The training engine containing the model and evaluation methods.
   :type solver: Engine
   :param epoch: The current training epoch, used for naming generated files. Defaults to 0.
   :type epoch: int, optional
   :param best_checkpoints: A list of tuples containing the metric and path of the best checkpoints.
   :type best_checkpoints: list, optional
   :param logger: The logging backend to use. Defaults to "logging".
   :type logger: Literal["wandb", "logging"], optional
   :param \*\*kwargs: Additional keyword arguments specific to the task, such as:
                      - output_generated_dir (str): Directory to save generated molecules (for diffusion).
                      - generative_analysis (bool): Whether to perform generative analysis (for diffusion).
                      - n_samples (int): Number of samples to generate (for diffusion).
                      - metric (str): The metric to return from generative analysis (for diffusion).

   :returns: A tuple containing the best performance metric and the list of best checkpoints.
   :rtype: Tuple[float, list]
