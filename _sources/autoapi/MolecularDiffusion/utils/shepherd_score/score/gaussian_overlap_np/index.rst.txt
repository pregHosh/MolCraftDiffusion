.. py:function:: get_linear_hard_sphere_overlap_np(centers_1: numpy.ndarray, centers_2: numpy.ndarray, min_dist: float) -> numpy.ndarray

   Compute linear hard sphere overlap.

   This function is linear based on the distance between centers
   For distance d
   d > min_dist: 0
   0 < d < min_dist: linear from 0 to 1
   d == 0: 1

   :returns: np.ndarray shape (1,) with the sum of hard sphere overlaps between)
