MolecularDiffusion.utils.shepherd_score.alignment.utils.se3
===========================================================

.. py:module:: MolecularDiffusion.utils.shepherd_score.alignment.utils.se3

.. autoapi-nested-parse::

   Functions used for SE(3) transformations. (Torch implementation).
   Has support for operations with batches.

   Namely, converting quaternions to rotation matrices, getting an SE(3) transform from SE(3)
   parameters, and applying the SE(3) transformation on a set of points.

   Credit to Lewis J. Martin as this was adapted from
   https://github.com/ljmartin/align/blob/main/0.2%20aligning%20principal%20moments%20of%20inertia.ipynb
   and PyTorch's implementations.

.. py:function:: apply_SE3_transform(points: torch.Tensor, SE3_transform: torch.Tensor) -> torch.Tensor

   Takes a point cloud and transforms it according to the provided SE3 transformation matrix.
   Supports batched and non-batched inputs.

   :param points: Set of coordinates representing a point cloud.
   :type points: torch.Tensor (batch, N, 3) or (N, 3)
   :param SE3_transform: SE(3) transformation matrix. If 'points' argument is batched, this one should be too.
   :type SE3_transform: torch.Tensor (batch, 4, 4) or (4, 4)

   :returns: **transformed_points** -- Set of coordinates transformed by the corresponding SE(3) transformation.
   :rtype: torch.Tensor (batch, N, 3) or (N, 3)


.. py:function:: apply_SO3_transform(points: torch.Tensor, SE3_transform: torch.Tensor) -> torch.Tensor

   Takes a point cloud and ONLY ROTATES it according to the provided SE3 transformation matrix.
   Supports batched and non-batched inputs.

   :param points: Set of coordinates representing a point cloud.
   :type points: torch.Tensor (batch, N, 3) or (N, 3)
   :param SE3_transform: SE(3) transformation matrix. If 'points' argument is batched, this one should be too.
   :type SE3_transform: torch.Tensor (batch, 4, 4) or (4, 4)

   :returns: **rotated_points** -- Set of coordinates rotated by the rotation component of the SE(3) transformation.
   :rtype: torch.Tensor (batch, N, 3) or (N, 3)


.. py:function:: get_SE3_transform(se3_params: torch.Tensor) -> torch.Tensor

   Constructs an SE(3) transformtion matrix from parameters.
   Supports batched and non-batched inputs.

   :param se3_params: Parameters for SE(3) transformation.
                      The first 4 values in the last dimension are quaternions of form (r,i,j,k)
                      and the last 3 values of the last dimension are the translations in (x,y,z).
   :type se3_params: torch.Tensor (batch, 7) or (7,)

   :returns: **se3_matrix** -- se3_params converted to a 4x4 SE(3) transformation matrix.
   :rtype: torch.Tensor (batch, 4, 4) or (4, 4)


.. py:function:: quaternions_to_rotation_matrix(quaternions: torch.Tensor) -> torch.Tensor

   Converts quaternion to a rotation matrix. Supports batched and non-batched inputs.
   Adapted from PyTorch3D:
   https://pytorch3d.readthedocs.io/en/latest/_modules/pytorch3d/transforms/rotation_conversions.html#quaternion_to_matrix

   :param quaternions: Quaternion parameters in (r,i,j,k) order. Accepts single set of parameters or a batched
                       set.
   :type quaternions: torch.Tensor (batch, 4) or (4,)

   :returns: **rotation_matrix** -- Rotation matrix converted from quaternion in batched or single instance form.
   :rtype: torch.Tensor (batch, 3, 3) or (3,3)
