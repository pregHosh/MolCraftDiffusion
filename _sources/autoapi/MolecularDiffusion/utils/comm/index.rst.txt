.. py:function:: cat(obj, dst=None)

   Concatenate any nested container of tensors along the 0-th axis.

   :param obj: any container object. Can be nested list, tuple or dict.
   :type obj: Object
   :param dst: rank of destination worker. If not specified, broadcast the result to all workers.
   :type dst: int, optional

   Example::

       >>> # assume 4 workers
       >>> rank = comm.get_rank()
       >>> rng = torch.arange(10)
       >>> obj = {"range": rng[rank * (rank + 1) // 2: (rank + 1) * (rank + 2) // 2]}
       >>> obj = comm.cat(obj)
       >>> assert torch.allclose(obj["range"], rng)

.. py:function:: reduce(obj, op='sum', dst=None)

   Reduce any nested container of tensors.

   :param obj: any container object. Can be nested list, tuple or dict.
   :type obj: Object
   :param op: element-wise reduction operator.
              Available operators are ``sum``, ``mean``, ``min``, ``max``, ``product``.
   :type op: str, optional
   :param dst: rank of destination worker. If not specified, broadcast the result to all workers.
   :type dst: int, optional

   Example::

       >>> # assume 4 workers
       >>> rank = comm.get_rank()
       >>> x = torch.rand(5)
       >>> obj = {"polynomial": x ** rank}
       >>> obj = comm.reduce(obj)
       >>> assert torch.allclose(obj["polynomial"], x ** 3 + x ** 2 + x + 1)


.. py:function:: stack(obj, dst=None)

   Stack any nested container of tensors. The new dimension will be added at the 0-th axis.

   :param obj: any container object. Can be nested list, tuple or dict.
   :type obj: Object
   :param dst: rank of destination worker. If not specified, broadcast the result to all workers.
   :type dst: int, optional

   Example::

       >>> # assume 4 workers
       >>> rank = comm.get_rank()
       >>> x = torch.rand(5)
       >>> obj = {"exponent": x ** rank}
       >>> obj = comm.stack(obj)
       >>> truth = torch.stack([torch.ones_like(x), x, x ** 2, x ** 3]
       >>> assert torch.allclose(obj["exponent"], truth))
