.. py:function:: download(url, path, save_file=None, md5=None)

   Download a file from the specified url.
   Skip the downloading step if there exists a file satisfying the given MD5.

   :param url: URL to download
   :type url: str
   :param path: path to store the downloaded file
   :type path: str
   :param save_file: name of save file. If not specified, infer the file name from the URL.
   :type save_file: str, optional
   :param md5: MD5 of the file
   :type md5: str, optional


.. py:function:: extract(zip_file, member=None)

   Extract files from a zip file. Currently, ``zip``, ``gz``, ``tar.gz``, ``tar`` file types are supported.

   :param zip_file: file name
   :type zip_file: str
   :param member: extract specific member from the zip file.
                  If not specified, extract all members.
   :type member: str, optional
