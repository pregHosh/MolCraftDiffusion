MolecularDiffusion.modules.tasks.diffusion_ldm
==============================================

.. py:module:: MolecularDiffusion.modules.tasks.diffusion_ldm

.. autoapi-nested-parse::

   LDM (VAE + DiT) tasks for MolecularDiffusion.

   This module provides:
   - VAETaskFactory / VAETask: Variational Autoencoder for learning latent representations
   - LDMTaskFactory / LDMTask: Latent Diffusion Model for generation

   Stage 1: Train VAE to learn latent space
   Stage 2: Train DiT on frozen VAE latents

.. py:class:: FlowMatchingInterpolant(min_t: float = 0.01, corrupt: bool = True, num_timesteps: int = 100, self_condition: bool = False, self_condition_prob: float = 0.5)

   Flow matching interpolant for latent diffusion.

   Matches reference implementation from all-atom-diffusion-transformer.
   Key conventions:
   - x_0 is NOISE (prior)
   - x_1 is CLEAN DATA (target)
   - Time flows from 0 (noise) to 1 (clean)

   :param min_t: Minimum time to sample (avoids boundary singularities)
   :param corrupt: Whether to corrupt samples during training
   :param num_timesteps: Number of timesteps for sampling
   :param self_condition: Whether to use self-conditioning
   :param self_condition_prob: Probability of using self-conditioning during training


   .. py:method:: corrupt_batch(batch)

      Corrupts a batch of data for training.

      :param batch: Dict with keys:
                    - x_1: Clean data (B, N, d)
                    - token_mask: Valid token mask (B, N)
                    - diffuse_mask: Mask for tokens to diffuse (B, N)

      :returns:     - x_t: Noisy data
                    - t: Sampled timesteps
      :rtype: Dict with added keys



   .. py:method:: sample(batch_size, num_tokens, emb_dim, model, mask=None, num_timesteps=None, x_0=None)

      Generate samples by integrating the flow ODE.

      :param batch_size: Number of samples
      :param num_tokens: Max tokens per sample
      :param emb_dim: Latent dimension
      :param model: Denoiser model (predicts x_1 from x_t, t)
      :param mask: Valid token mask (B, N)
      :param num_timesteps: Number of integration steps
      :param x_0: Initial noise (if None, sampled)

      :returns: Dict with tokens_traj and clean_traj lists
