.. py:class:: SinusoidEncoding(posenc_dim, max_len=100, random_permute=False)

   Bases: :py:obj:`PositionalEncoding`


   Classic sinusoidal positional encoding (Vaswani et al., 2017).

   Initialize the positional encoding.

   :param posenc_dim: Size of the embedding dimension.
   :param max_len: Maximum sequence length supported. `seq_len` passed to
                   `forward` must not exceed this value.
   :param random_permute: If `True`, the positions are randomly permuted for each
                          sample (useful as lightweight data augmentation but destroys absolute
                          ordering).


   .. py:method:: forward(batch_size: int, seq_len: int)

      Return positional embeddings of shape `(batch_size, seq_len, posenc_dim)`.

      :param batch_size: Number of samples in the batch.
      :param seq_len: Length of the sequence.

      .. note:: `seq_len` must not exceed the `max_len` passed at construction.
