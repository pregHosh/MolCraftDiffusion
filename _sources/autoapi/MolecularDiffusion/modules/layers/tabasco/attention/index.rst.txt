.. py:class:: AdaLNAttention(dim: int, num_heads: int, dropout: float = 0.0, bias: bool = True, batch_first: bool = True, norm_eps: float = 1e-05)

   Bases: :py:obj:`torch.nn.Module`


   Attention module with Adaptive Layer Normalization (AdaLN).

   This implements an attention mechanism with adaptive layer normalization,
   which allows for conditioning the layer normalization parameters based on
   additional inputs.

   Initialize the AdaLNAttention module.

   :param dim: Input dimension
   :param num_heads: Number of attention heads
   :param dropout: Dropout probability
   :param bias: Whether to use bias in linear projections
   :param batch_first: Whether input is batch-first (batch, seq, features)
   :param norm_eps: Epsilon value for layer normalization


   .. py:method:: forward(x: torch.Tensor, context: torch.Tensor, key_padding_mask: Optional[torch.Tensor] = None, attn_mask: Optional[torch.Tensor] = None, need_weights: bool = False) -> torch.Tensor

      Forward pass through the AdaLN attention layer.

      :param x: Input tensor of shape [batch_size, seq_len, dim]
      :param context: Context tensor for conditioning the layer norm parameters
                      Shape: [batch_size, context_dim] or [batch_size, seq_len, dim]
      :param key_padding_mask: Boolean mask for keys to ignore (True means ignore)
                               Shape: [batch_size, seq_len]
      :param attn_mask: Mask to prevent attention to certain positions
                        Shape: [seq_len, seq_len] or [batch_size, seq_len, seq_len]
      :param need_weights: Whether to return attention weights

      :returns: Output tensor of shape [batch_size, seq_len, dim]
                (and optionally attention weights if need_weights=True)

   A wrapper around PyTorch's MultiheadAttention module with a simplified interface.

   This class provides a more convenient interface for using multi-head attention
   in transformer architectures, handling the reshaping and masking operations.

   Initialize the Attention module.

   :param dim: Input and output dimension
   :param num_heads: Number of attention heads
   :param dropout: Dropout probability for attention weights
   :param bias: Whether to include bias terms in the projection layers
   :param batch_first: Whether input tensors are in batch-first format (batch, seq, features)


   .. py:method:: forward(query: torch.Tensor, key: Optional[torch.Tensor] = None, value: Optional[torch.Tensor] = None, key_padding_mask: Optional[torch.Tensor] = None, attn_mask: Optional[torch.Tensor] = None, need_weights: bool = False) -> torch.Tensor

      Forward pass through the multi-head attention layer.

      :param query: Query tensor of shape [batch_size, seq_len_q, dim]
      :param key: Key tensor of shape [batch_size, seq_len_k, dim] (defaults to query if None)
      :param value: Value tensor of shape [batch_size, seq_len_v, dim] (defaults to key if None)
      :param key_padding_mask: Boolean mask for keys to ignore (True means ignore)
                               Shape: [batch_size, seq_len_k]
      :param attn_mask: Mask to prevent attention to certain positions

      :param need_weights: Whether to return attention weights

      :returns: Output tensor of shape [batch_size, seq_len_q, dim]
                (and optionally attention weights if need_weights=True)
