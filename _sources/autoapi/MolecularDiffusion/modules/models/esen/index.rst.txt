.. py:class:: eSEN_Encoder(max_num_elements: int = 100, sphere_channels: int = 128, lmax: int = 2, mmax: int = 2, grid_resolution: int | None = None, max_neighbors: int = 300, cutoff: float = 5.0, edge_channels: int = 128, distance_function: str = 'gaussian', num_distance_basis: int = 512, num_layers: int = 2, hidden_channels: int = 128, norm_type: str = 'rms_norm_sh', act_type: str = 's2', mlp_type: str = 'grid', use_envelope: bool = False, activation_checkpointing: bool = False, sphere_embedding_type: str = 'embedding', **kwargs)

   Bases: :py:obj:`eSEN_Backbone`


   eSEN Encoder for VAE tasks.

   Wraps eSEN_Backbone with fixed configuration for VAE encoding:
   - No force/stress regression
   - No position updates
   - Standard embedding
   - No global attributes
   - No OTF graph (assumes pre-computed or standard radius graph)


.. py:class:: eSEN_VelocityFFN(sphere_channels: int, hidden_channels: int, lmax: int)

   Bases: :py:obj:`torch.nn.Module`


   Native eSEN equivariant FFN for coordinate updates.
   Mirrors the equiformer FeedForwardNetwork pattern but operates on
   eSEN's native [N, (lmax+1)^2, sphere_channels] tensors.

   Forward: x_message -> SO3_Linear -> GateActivation -> SO3_Linear(out=1)
            -> l=1 slice [:, 1:4, 0] -> [N, 3] position delta
