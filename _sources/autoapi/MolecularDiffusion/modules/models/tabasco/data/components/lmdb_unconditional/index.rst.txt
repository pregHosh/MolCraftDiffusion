.. py:class:: UnconditionalLMDBDataset(data_dir: str, split: str, add_random_rotation: bool = True, add_random_permutation: bool = True, reorder_to_smiles_order: bool = False, remove_hydrogens: bool = True, single_sample: bool = False, limit_samples: int = None, lmdb_dir: str = None)

   Bases: :py:obj:`MolecularDiffusion.modules.models.tabasco.data.components.lmdb_base.BaseLMDBDataset`


   Adapted from Charlie Harris' code, originally based on a PyG dataset of
   protein-ligand complexes for experimental structures found in CrossDocked2020 dataset.
   Unconditional ligand dataset backed by an LMDB file.

   Initialize the dataset.

   :param data_dir: Path to the serialized list of `(Optional[Protein], rdkit.Chem.Mol)` tuples.
   :param split: Name of the dataset split.
   :param add_random_rotation: Randomly rotate ligand coordinates on access.
   :param add_random_permutation: Randomly permute atom order on access.
   :param reorder_to_smiles_order: Sort atoms to match canonical SMILES before tensor conversion.
   :param remove_hydrogens: Strip explicit hydrogens prior to processing.
   :param single_sample: When `True`, always return the first entry (useful for debugging).
   :param limit_samples: Optional cap on number of molecules processed.
   :param lmdb_dir: Directory in which the LMDB and stats YAML will be stored.
