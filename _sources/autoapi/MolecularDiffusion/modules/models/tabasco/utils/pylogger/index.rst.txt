.. py:class:: RankedLogger(name: str = __name__, rank_zero_only: bool = False, extra: Optional[Mapping[str, object]] = None)

   Bases: :py:obj:`logging.LoggerAdapter`


   A multi-GPU-friendly python command line logger.

   Initializes a multi-GPU-friendly python command line logger that logs on all processes
   with their rank prefixed in the log message.

   :param name: Name of the Python logger to wrap.
   :param rank_zero_only: If True, emit messages only on rank 0.
   :param extra: Optional context dictionary forwarded to
                 `logging.LoggerAdapter`.


   .. py:method:: log(level: int, msg: str, rank: Optional[int] = None, *args, **kwargs) -> None

      Delegate a log call to the underlying logger, after prefixing its message with the rank
      of the process it's being logged from. If `'rank'` is provided, then the log will only
      occur on that rank/process.

      :param level: Standard `logging` level (e.g., `logging.INFO`).
      :param msg: Message string.
      :param rank: If provided, emit only from this rank. Ignored when
                   `rank_zero_only` is set.
      :param \*args: Positional arguments forwarded to the underlying logger.
      :param \*\*kwargs: Keyword arguments forwarded to the underlying logger.



   .. py:attribute:: rank_zero_only
      :value: False
