.. py:function:: align_model_states(model_outputs, D_theta, cdt_dict, params, num_repeats: int = 5, trans_init: bool = False, lr: float = 0.1, max_steps: int = 10, mode: str = 'so3', verbose: bool = True)

   EDM version of align_model_states.

   Identical to the DDPM version except D_theta (the EDM denoiser output) is
   passed instead of x0_pred.  For EDM, D_theta IS the clean x0 prediction,
   so the surface point positions and ESP charges are read from:
       D_theta['x3_pos']   (vs DDPM x0_pred['x3_pos_0'])
       D_theta['x3_x']     (vs DDPM x0_pred['x3_x_0'])

   :param model_outputs: All positional outputs keyed by modality; every 'pos' key is transformed
                         under the recovered SE3/SO3 alignment.
   :type model_outputs: dict
   :param D_theta: EDM denoiser output from _inference_step_comp_edm. Keys include
                   'x3_pos' (surface point positions) and 'x3_x' (ESP features).
   :type D_theta: dict
   :param cdt_dict: Condition dict with 'surface' (ref surface points) and
                    'electrostatics' (ref ESP values).
   :type cdt_dict: dict
   :param params: Model params dict (used for x3 feature scaling).
   :type params: dict
   :param num_repeats: Number of SE3 init restarts for the overlay optimiser.
   :type num_repeats: int
   :param lr: Learning rate for the overlay optimiser.
   :type lr: float
   :param max_steps: Max optimisation steps.
   :type max_steps: int
   :param mode: 'so3'  - apply rotation only (strip translation after fitting).
                'se3'  - apply full SE3 transform.
   :type mode: str
   :param verbose:
   :type verbose: bool

   :returns: * **model_outputs** (*dict  (positions transformed in-place)*)
             * **se3_transform** (*torch.Tensor (4, 4)*)

.. py:function:: atom_condition_kwargs_from_profile(profile: MolecularDiffusion.modules.models.shepherd2.interaction_profile.InteractionProfile | MolecularDiffusion.modules.models.shepherd2.interaction_profile.ConditionAtoms, scaffold_conditioning: bool = False, inpaint: MolecularDiffusion.modules.models.shepherd2.interaction_profile.InpaintAdvancedOptions | None = None, center_of_mass: numpy.ndarray | None = np.zeros(3)) -> dict

   Translate an InteractionProfile/ConditionAtoms (+ optional InpaintAdvancedOptions)
   into the kwargs dict expected by gen_x1_edm_inpainting_dict — the same shape
   produced by return_atom_condition_dict.

   Pure interface adapter: does not change what gen_x1_edm_inpainting_dict or
   generate_composition compute. Note gen_x1_edm_inpainting_dict has no exit-vector-
   aware bond inpainting (unlike the newer inference.sampler.generate), so
   ConditionAtoms.exit_vector_inds is not forwarded — carrying it through would not
   change behavior, since it isn't consumed downstream.

   :param profile: An InteractionProfile with `condition_atoms` set (e.g. via
                   `with_condition_atoms`/`from_condition_atoms`), or a bare ConditionAtoms.
   :type profile: InteractionProfile | ConditionAtoms
   :param scaffold_conditioning:
   :type scaffold_conditioning: bool (default=False)
   :param inpaint: Overrides for x1 inpaint flags / stop-time knobs, merged and resolved the
                   same way `generate()` does.
   :type inpaint: Optional[InpaintAdvancedOptions] (default=None)
   :param center_of_mass: Resolved coordinate-frame offset to center atom positions about, as
                          produced by generate_composition's ``condition_center_of_mass``
                          handling (``np.zeros(3)`` for ``'origin'``, ``None`` for ``'auto'`` --
                          auto-derive from the scaffold COM inside gen_x1_edm_inpainting_dict --
                          or an explicit length-3 array). Not derived from ``profile`` itself:
                          ``InteractionProfile.to_generate_kwargs()['center_of_mass']`` is always
                          ``np.zeros(3)`` and is intentionally ignored here.
   :type center_of_mass: np.ndarray (3,) | None (default=np.zeros(3))

   :returns: **dict**
   :rtype: kwargs suitable for gen_x1_edm_inpainting_dict.

.. py:function:: optimize_SO3_esp_overlay(ref_points: torch.Tensor, fit_points: torch.Tensor, ref_charges: torch.Tensor, fit_charges: torch.Tensor, alpha: float, lam: float, num_repeats: int = 50, lr: float = 0.1, max_num_steps: int = 200, verbose: bool = False) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]

   Same interface as optimize_ROCS_esp_overlay but restricts optimization to SO3 (rotation only).
   Translation is frozen at the CoM-aligning value computed during initialization - gradients are
   never propagated through the translation indices of se3_params.

   The trick: split the (num_repeats, 7) initialization into
     quat_params  (num_repeats, 4)  requires_grad=True   <- optimized
     fixed_trans  (num_repeats, 3)  requires_grad=False  <- frozen
   then rebuild se3_params = cat([quat_params, fixed_trans]) each step so autograd only
   touches the rotation leaf. No changes to any underlying objective or transform functions.

   :param ref_points: Reference and fit point clouds to align.
   :type ref_points: torch.Tensor
   :param fit_points: Reference and fit point clouds to align.
   :type fit_points: torch.Tensor
   :param ref_charges: Per-point charges/features used by the ESP similarity objective.
   :type ref_charges: torch.Tensor
   :param fit_charges: Per-point charges/features used by the ESP similarity objective.
   :type fit_charges: torch.Tensor
   :param alpha: ESP similarity scoring hyperparameters.
   :type alpha: float
   :param lam: ESP similarity scoring hyperparameters.
   :type lam: float
   :param num_repeats: Number of random restarts.
   :type num_repeats: int (default=50)
   :param lr:
   :type lr: float (default=0.1)
   :param max_num_steps:
   :type max_num_steps: int (default=200)
   :param verbose:
   :type verbose: bool (default=False)

   :returns: * **aligned_points** (*torch.Tensor (M, 3)*)
             * **SE3_transform** (*torch.Tensor (4, 4)*)
             * **score** (*torch.Tensor (1,)*)
