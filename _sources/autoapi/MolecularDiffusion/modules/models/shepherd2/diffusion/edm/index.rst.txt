      Given a clean data sample, it adds noise to the data sample for a given noise level, sigma.

      :param clean_input:
      :type clean_input: (N, D) array of input features.
      :param sigma:
      :type sigma: float of noise level.
      :param c_in:
      :type c_in: float of input scaling factor.
      :param remove_COM_from_noise:
      :type remove_COM_from_noise: boolean flag to remove COM from noise.
      :param mask:
      :type mask: boolean mask where virtual node is False and non-virtual node is True.
      :param scale_by_sigma_data: Helpful for models that expect input features to be in the same units as the data.
      :type scale_by_sigma_data: boolean flag to scale output by sigma_data.

      :returns: c_in * (inp + noise)
                optionally scaled by sigma_data if scale_by_sigma_data is True
      :rtype: (N, D) array of forward-noised features
