   Fragment node ids are just the order in which they are added.
   Each fragment knows about its reaction center occupation statuses.

      Add a new fragment to the molecule fragment graph.

      :param new_frag_global_id: The global id of the new fragment as indexed by our vocabulary.

      :type self_reaction_center_idx: int
      :param other_reaction_center_idx: The index of the reaction center we want to occupy on the other fragment.
      :type other_reaction_center_idx: int

      :returns: The updated fragment and atom graphs.
