.. py:function:: center(coords: torch.Tensor, mask: torch.Tensor, custom_center: torch.Tensor = None, apply_mask: torch.Tensor = None) -> torch.Tensor

   Center coordinates by mask; supports [N,3], [B,N,3], or [B,S,N,3].

   :param coords: Coordinates tensor [N,3], [B,N,3], or [B,S,N,3]
   :param mask: Mask for computing center
   :param custom_center: Optional pre-computed center to subtract
   :param apply_mask: Optional separate mask for zeroing after centering.
                      If None, NO zeroing is applied (matches old behavior).
