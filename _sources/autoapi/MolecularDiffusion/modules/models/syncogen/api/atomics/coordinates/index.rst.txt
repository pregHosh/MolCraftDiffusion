.. py:class:: Coordinates(coordinates: torch.Tensor, atom_mask: Optional[torch.Tensor] = None, is_batched: Optional[bool] = None)

   Coordinates class for handling molecular coordinates.

   Use factory methods for construction:
       - Coordinates.from_tensor(coordinates, atom_mask)
       - Coordinates.random(shape, atom_mask, device)

   Or use the constructor directly with a coordinates tensor.

   Initialize from coordinates tensor (canonical constructor).

   :param coordinates: Coordinate tensor, shape (N, 3) or (B, N, 3)
   :param atom_mask: Optional mask tensor, shape (N,) or (B, N). Defaults to all ones.
   :param is_batched: Whether this is batched. Inferred from coordinates.dim() if None.


   .. py:method:: apply_mask(mask: torch.Tensor)

      Apply a mask to the coordinates tensor.

      :param mask: Tensor of shape matching self.tensor up to the last dimension



   .. py:method:: attach_bonds(bonds: torch.Tensor, bonds_mask: torch.Tensor)

      Attach bonds to coordinates with explicit mask.

      :param bonds: [..., n_bonds, 3] where each entry is (i_flat, j_flat, bond_type_index)
      :param bonds_mask: [..., n_bonds] boolean mask of valid bonds



   .. py:method:: attach_pharmacophores(pharm_coords: torch.Tensor, pharm_padding_mask: torch.Tensor)

      Attach pharmacophores to coordinates with explicit mask.

      - Keeps atoms and pharm as separate tensors internally
      - Combined mask is computed dynamically via property
