.. py:function:: build_molecule(nodes: torch.Tensor, decoded_edges: torch.Tensor, smiles: bool = False) -> str

   Build a molecule from model outputs. Used in calculating pvalid.

   :param nodes: Tensor of node indices [n_nodes]
   :param decoded_edges: Tensor of decoded model outputs [n_edges, 5] containing
                         (reaction_id, node1_order, node2_order, center1_idx, center2_idx).
                         These are not the same as actions for adding to MFG and must be converted.
   :param smiles: Whether to return a SMILES string or an RDKit molecule

   :returns: SMILES string of the molecule


.. py:function:: build_molecules_from_graphs(graphs: MolecularDiffusion.modules.models.syncogen.api.graph.graph.BBRxnGraph, coords: Optional[torch.Tensor] = None) -> List[Optional[rdkit.Chem.Mol]]

   Build RDKit molecules from graphs with optional coordinates.

   :param graphs: BBRxnGraph object (batched or unbatched)
   :param coords: Optional [B, N, 3] coordinate tensor

   :returns: List of RDKit molecules (None for failed reconstructions).

.. py:function:: mol_to_pharm_cond(mol: rdkit.Chem.Mol, batch_size: int, n_subset: int, center: bool = True, normalize: bool = True) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]

   Extract pharmacophore conditioning from a reference molecule.

   :param mol: RDKit molecule with conformer
   :param batch_size: Number of copies to create (for batched conditioning)
   :param n_subset: Max pharmacophores per sample (randomly subsampled per batch element)
   :param center: Center molecule coordinates before extraction
   :param normalize: Normalize positions by COORDS_STD

   :returns: [batch_size, n_subset, n_pharm_types] one-hot pharmacophore types
             pos: [batch_size, n_subset, 3] pharmacophore positions
             mask: [batch_size, n_subset] padding mask
   :rtype: types
