.. py:class:: DiT(d_x: int = 8, d_model: int = 384, num_layers: int = 12, nhead: int = 6, mlp_ratio: float = 4.0, class_dropout_prob: float = 0.1, num_datasets: int = 2, num_spacegroups: int = 230, d_context: int = 0)

   Bases: :py:obj:`torch.nn.Module`


   Diffusion Transformer denoiser.

   :param d_x: Latent token dimension (must match VAE latent_dim)
   :param d_model: Model hidden dimension
   :param num_layers: Number of Transformer layers
   :param nhead: Number of attention heads
   :param mlp_ratio: Ratio of hidden to input dimension in MLP
   :param class_dropout_prob: Probability of dropping class labels for CFG
   :param num_datasets: Number of datasets (for multi-dataset training, default 2)
   :param num_spacegroups: Number of spacegroups (for crystals, default 230)
   :param d_context: Width of a per-molecule property vector (0 = unconditional).
                     When > 0 a `context_embedder` MLP maps it to d_model and the result
                     is ADDED to the conditioning vector c. 0 creates no module, so the
                     state_dict of every existing checkpoint is unchanged.


   .. py:method:: enable_context(d_context: int)

      Add the property-context MLP (idempotent). Also called by LDMTaskFactory, since
      the denoiser may already be instantiated by Hydra before condition_names is known.



   .. py:method:: forward(x, t, mask, dataset_idx=None, spacegroup=None, x_sc=None, context=None)

      Forward pass of DiT.

      :param x: Noisy latent tokens (B, N, d_x)
      :param t: Timestep for each sample (B,) or (B, 1)
      :param mask: Valid token mask, True if valid (B, N)
      :param dataset_idx: Dataset index (B,) - default 1 for molecules
      :param spacegroup: Spacegroup index (B,) - default 0 for molecules
      :param x_sc: Self-conditioning input (B, N, d_x) - optional
      :param context: Per-molecule property vector (B, d_context) - required iff
                      the model was built with d_context > 0 (null = the caller's
                      mask_value vector; the caller owns dropout/null semantics)

      :returns: Predicted clean latent (B, N, d_x)
