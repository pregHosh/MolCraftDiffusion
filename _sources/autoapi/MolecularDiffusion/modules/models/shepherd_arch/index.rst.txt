MolecularDiffusion.modules.models.shepherd_arch
===============================================

.. py:module:: MolecularDiffusion.modules.models.shepherd_arch

.. autoapi-nested-parse::

   ShEPhERD model architecture ported into MolecularDiffusion.

   This package contains the ShEPhERD (Shape, Electrostatics, and Pharmacophores
   for Drug Design) multi-modal denoiser architecture, adapted to use
   MolecularDiffusion's own equiformer_v2 layers.
