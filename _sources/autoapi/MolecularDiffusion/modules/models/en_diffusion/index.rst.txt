      Performs a sanity check on the generated molecule (x, h) by computing its loss.
      If the loss is infinite, it attempts to find a "clean" molecule from previous frames
      in the sampling chain by iterating backward and re-sampling x and h from z_0.
      This helps to recover from potential numerical instabilities during sampling.

      :param x: Current atom positions (B, N, 3).
      :type x: torch.Tensor
      :param h: Dictionary of atom features {'categorical', 'integer', 'extra'}.
      :type h: dict
      :param node_mask: Mask indicating valid nodes (B, N, 1).
      :type node_mask: torch.Tensor
      :param edge_mask: Mask indicating valid edges (B, N, N).
      :type edge_mask: torch.Tensor
      :param context: Context tensor for the diffusion model.
      :type context: torch.Tensor
      :param chain: A tensor containing intermediate states (z) from the sampling process.
                    Shape: (num_frames, B, N, D_latent).
      :type chain: torch.Tensor
      :param n_frame_look_back: Number of frames to look back in the chain
                                if the current molecule is "unclean". Defaults to 4.
      :type n_frame_look_back: int, optional

      :returns:

                A tuple containing the (potentially corrected) atom positions (x)
                                          and atom features (h) that result in a finite loss.

              Guided sampling from the generative model.

              Parameters:
              - n_samples (int): Number of samples to generate.

              - inpaint_cfgs (dict, optional): Configuration for inpainting.

              - outpaint_cfgs (dict, optional): Configuration for outpainting.

                      - t_critical (float, optional): Timestep threshold for applying reference tensor constraints. Defaults to None.
      `               - connector_index (torch.Tensor, optional): Indices of connector nodes for outpainting. Defaults to an empty tensor.
                      - seed_dist (float, optional): Distance of the seed from the connector atom (used if n_bq_atom == 0)..

      Samples from zs ~ p(zs | zt) using classifier-free guidance (CFG).

      This method adjusts the diffusion sampling process by guiding the noise prediction
      towards a conditional distribution and away from an unconditional (or negative) one.
      It also supports inpainting-style generation where a reference part of the structure
      can be fixed.

      :param s: The current timestep, s.
      :type s: torch.Tensor
      :param t: The next timestep, t.
      :type t: torch.Tensor
      :param zt: The noisy data at timestep t.
      :type zt: torch.Tensor
      :param node_mask: Mask for nodes in the graph.
      :type node_mask: torch.Tensor
      :param edge_mask: Mask for edges in the graph.
      :type edge_mask: torch.Tensor
      :param context: The conditional information for guidance.
      :type context: torch.Tensor
      :param scale: The strength of the classifier-free guidance.
      :type scale: float
      :param fix_noise: If True, uses fixed noise for sampling. Defaults to False.
      :type fix_noise: bool, optional
      :param context_negative: Negative conditional information for guidance.
                               If None, unconditional generation is used as the negative target. Defaults to None.
      :type context_negative: torch.Tensor, optional
      :param structure_guidance: If inpaint or outpaint, applies structure guidance. Defaults to False.
      :type structure_guidance: bool, optional
      :param t_critical: Timestep threshold for applying reference tensor constraints. Defaults to None.
      :type t_critical: float, optional
      :param mask_node_index: List of node indices to mask during inpaiting. Defaults to [].
      :type mask_node_index: list, optional
      :param scale_schedule_type: Type of scheduler for CFG scale. [Available: 'linear', 'cosine']. Defaults to None.
      :type scale_schedule_type: str, optional

      :returns: The sampled data `zs` at timestep `s`.
      :rtype: torch.Tensor

   Variance-Preserving Inverse Sigmoid SNR (VP-ISSNR) schedule based on:
   τ²(t) = 1 (i.e., total variance is constant)
   γ²(t) = ((1 / (t * (tmax - tmin) + tmin)) - 1)^(2η) * exp(2κ)

   :param timesteps: number of steps (T)
   :type timesteps: int
   :param eta: controls steepness of SNR decay
   :type eta: float
   :param kappa: controls the offset of SNR
   :type kappa: float
   :param tmin: min effective time (0 < tmin < 1)
   :type tmin: float
   :param tmax: max effective time (0 < tmax < 1)
   :type tmax: float

   :returns: shape (timesteps + 1, len(nu_array))
   :rtype: alphas2s (np.ndarray)
