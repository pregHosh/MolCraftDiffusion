   Equivariant Graph Neural Network (EGNN) module for processing graph-structured data with node features and coordinates.

   This model supports optional context conditioning, sinusoidal embeddings, cosine edge features, and adapter modules for context.
   It is designed for tasks where equivariance to geometric transformations is important, such as molecular modeling.

   Dynamics model for Equivariant Diffusion Models (EDMs) using EGNNs.

   This class wraps an EGNN to model the time evolution of node features and coordinates, supporting context conditioning, time conditioning, and adapter modules.
   It is suitable for molecular dynamics, generative modeling, and other tasks requiring equivariant dynamics on graphs.

   :param in_node_nf: Number of input node features per node (including time if used).
   :type in_node_nf: int
   :param context_node_nf: Number of context features per node.
   :type context_node_nf: int
   :param n_dims: Number of spatial dimensions (e.g., 3 for 3D coordinates).
   :type n_dims: int
   :param hidden_nf: Number of hidden features in the EGNN.
   :type hidden_nf: int
   :param act_fn: Activation function.
   :type act_fn: nn.Module
   :param n_layers: Number of EGNN blocks.
   :type n_layers: int
   :param attention: Whether to use attention in the EGNN.
   :type attention: bool
   :param condition_time: Whether to condition on time.
   :type condition_time: bool
   :param tanh: Whether to use tanh in the EGNN.
   :type tanh: bool
   :param norm_constant: Normalization constant for the EGNN.
   :type norm_constant: float
   :param inv_sublayers: Number of sublayers in the EGNN.
   :type inv_sublayers: int
   :param sin_embedding: Whether to use sinusoidal embedding in the EGNN.
   :type sin_embedding: bool
   :param include_cosine: Whether to include cosine as edge features.
   :type include_cosine: bool
   :param normalization_factor: Normalization factor for the EGNN.
   :type normalization_factor: float
   :param aggregation_method: Aggregation method for the EGNN.
   :type aggregation_method: str
   :param dropout: Dropout probability.
   :type dropout: float
   :param normalization: Whether to use normalization in the EGNN.
   :type normalization: bool
   :param use_adapter_module: Whether to use adapter module for context. (Legacy, prefer adapter_indices.)
   :type use_adapter_module: bool

   adapter_indices (list): Column indices of context tensor routed through adapter MLPs.
   concat_indices (list): Column indices of context tensor concatenated to input features.
